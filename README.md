# Payment Static Web

A simple static Payment Application hosted on an Ubuntu server using Nginx.

## Project Structure

payment-static-web/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Nginx
- Ubuntu Linux

## Deployment

Application directory:

/opt/payment-static-web

Nginx is used to serve the static website on port 80.
